# Q1 — Mapeamento OWASP Top 10

| Código | Descrição da vulnerabilidade | OWASP Top 10 (2021) | Vetor de ataque |

| V1 | Chave secreta do JWT escrita diretamente no código-fonte | A02 — Cryptographic Failures | Quem obtiver o código pode descobrir o segredo e forjar tokens JWT válidos. |
| V2 | SQL construído por concatenação de email e senha | A03 — Injection | O atacante manipula o campo de login para alterar a consulta SQL. |
| V3 | JWT sem expiração | A07 — Identification and Authentication Failures | Um token roubado permanece válido indefinidamente, aumentando a janela de abuso. |
| V4 | Token e role retornados diretamente no corpo da resposta | A07 — Identification and Authentication Failures | O cliente recebe credenciais e informação de autorização que não deveriam ser expostas dessa forma. |
| V5 | Token recebido diretamente pelo header sem tratamento seguro de transporte | A07 — Identification and Authentication Failures | Um token obtido por interceptação/roubo pode ser reutilizado para autenticação. |
| V6 | ID do pedido inserido diretamente na SQL | A03 — Injection | O atacante pode alterar o parâmetro `id` para injetar SQL. |
| V7 | Ausência de verificação de ownership | A01 — Broken Access Control | Usuário autenticado consulta o pedido de outro usuário alterando o ID. |
| V8 | Ausência de validação do corpo da requisição | A04 — Insecure Design | Entradas inesperadas ou malformadas chegam à lógica de negócio. |
| V9 | Preço recebido do cliente | A04 — Insecure Design | Cliente altera `price` para reduzir artificialmente o valor do pedido. |
| V10 | Rota administrativa sem verificação de role | A01 — Broken Access Control | Qualquer usuário autenticado pode acessar a listagem administrativa. |
| V11 | Comunicação do frontend com HTTP | A02 — Cryptographic Failures | Em rede insegura, dados e credenciais podem ser interceptados ou modificados. |
| V12 | Token armazenado em `localStorage` | A02 — Cryptographic Failures | XSS pode ler o token e enviá-lo ao atacante. |
| V13 | Role armazenada no `localStorage` | A01 — Broken Access Control | O usuário pode alterar o valor local, embora a autorização correta deva ocorrer no servidor. |
| V14 | Painel administrativo controlado pelo frontend | A01 — Broken Access Control | Esconder/mostrar interface não é mecanismo de autorização; o servidor precisa verificar a permissão. |
| V15 | `dangerouslySetInnerHTML` com conteúdo não sanitizado | A03 — Injection | Comentário malicioso pode executar JavaScript no navegador de outro usuário. |
| V16 | CORS aceita qualquer origem | A05 — Security Misconfiguration | Qualquer origem pode tentar interagir com a API, ampliando a superfície de ataque. |
| V17 | Corpo JSON sem limite de tamanho | A05 — Security Misconfiguration | Requisições excessivamente grandes podem consumir recursos do servidor. |
| V18 | Ausência de rate limiting | A05 — Security Misconfiguration | Atacante pode realizar grande quantidade de requisições, inclusive tentativas automatizadas de login. |
| V19 | Ausência de headers de segurança/Helmet | A05 — Security Misconfiguration | O servidor deixa de aplicar diversas proteções HTTP recomendadas. |
| V20 | Stack trace exposto ao cliente | A05 — Security Misconfiguration | Mensagens internas revelam detalhes da implementação que podem auxiliar ataques. |
