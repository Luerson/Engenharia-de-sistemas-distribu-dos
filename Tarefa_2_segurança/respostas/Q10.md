# Q10 — Pipeline DevSecOps

| Etapa | Ferramenta | O que detecta | V1–V20 relacionado |
|---|---|---|---|
| Pre-commit | Gitleaks + ESLint | Secrets versionados e problemas básicos no código | V1, V12, V13, V15 |
| Build | npm audit | Dependências com vulnerabilidades conhecidas | Complementa a análise; especialmente útil contra componentes vulneráveis |
| Test | Jest/Supertest + testes de segurança | SQLi, controle de acesso, validação e regras de negócio | V2, V6, V7, V8, V9, V10 |
| Deploy | SAST (Semgrep/SonarQube) + revisão de configuração | Padrões vulneráveis no código e configurações inseguras | V1–V10, V15–V20 |
| Runtime | DAST (OWASP ZAP) + logs/monitoramento | Vulnerabilidades observáveis na aplicação em execução | V2, V6, V7, V10, V15–V20 |

## Fluxo

```text
Commit
  ↓
Pre-commit: secrets + lint
  ↓
Build + dependency scan
  ↓
Testes automatizados
  ↓
SAST
  ↓
DAST em ambiente de teste
  ↓
Deploy
  ↓
Monitoramento/runtime
```

O pipeline deve bloquear o avanço quando houver vulnerabilidades críticas previamente definidas como impeditivas. Resultados e exceções devem ser registrados para auditoria.
