## Observações

A implementação utiliza PostgreSQL como exemplo de banco porque o enunciado não especifica o driver. O objeto `db` deve ser ligado ao pool de conexão da aplicação real.

Também é necessário instalar as dependências correspondentes, por exemplo:

```bash
npm install express jsonwebtoken bcrypt zod helmet express-rate-limit cookie-parser cors
```

As variáveis de ambiente esperadas incluem:

```text
JWT_ACCESS_SECRET=<segredo-forte>
JWT_REFRESH_SECRET=<segredo-forte>
SPA_ORIGIN=https://app.gofood.example
NODE_ENV=production
PORT=3000
```

Os segredos não devem ser versionados no Git.
